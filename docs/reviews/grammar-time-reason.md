# 文法：時間與進程、原因與判斷的獨立檢查

本次逐筆重讀 `src/data/grammar/time-reason.ts` 的 10 項文法、20 句例句及 30 題練習。檢查內容包含接續、繁中語意、說明與易混淆提醒，以及各題情境、四個選項、正解、逐項理由和全部日文假名。這是 AI 輔助的獨立交叉檢查，未經日語教師或母語者全面審訂；本輪未逐項查閱外部文法書，不宣稱有外部專家或參考書逐條認證。

## 逐項檢查重點

| 文法 | 本次確認的語義界線 |
| --- | --- |
| うちに | 區分趁狀態改變之前行動，以及持續做某事時不知不覺發生變化；未把兩者限縮為有意識的趁機行動。 |
| たびに | 每次事件都有相同或相關經驗，不是單次先後；對自然規律使用「通常用と更自然」而非絕對禁止。 |
| 最中に | 活動進行的當下，常有打斷或不方便的事件；不等同尚未開始、剛做完。 |
| ところに | 依動詞形式區分正要做、正在做及剛做完；後項事件進入前項情境，不能一律翻成正在進行。 |
| ついでに | 主要行程與順便完成的附帶行動，不是取代、必要條件或每次反覆。 |
| おかげで | 正面因果與感謝；保留反語例外，不把所有用例都絕對限定為好事。 |
| せいで | 負面因果與責怪；區分不確定原因時的せいか，並提醒對人使用的語氣。 |
| はずだ | 依線索推斷照理成立，不是義務、命令或已親眼確認；不宣稱預期必然等於事實。 |
| わけではない | 修正過度推論、部分否定及雙重否定；並非全盤否定，也不等同不可能。 |
| わけがない | 說話者有根據的強烈否定，不等同客觀證明不可能；區分わけではない與わけにはいかない。 |

30 題均依其明示的情境及指示檢查正解與干擾選項。接續題明確指定練習的文法形式，語意與情境題採繁中解讀選項，避免將可互換的日文近義表達直接當成錯誤答案。

## 實際修改

- 補上「ところに」原接續表漏列的 **動詞辭書形＋ところに**，例如「出かけるところに」。保留其他三種接續，並將第一個例句改為此形式，讓文法表與實際示範一致。
- 調整同項接續題中「ところを」的理由，改為說明其常接對場面中的人施加作用的表達，與本題朋友到來的情境不同；避免只用「是否他動詞」作概括判斷。

以上修改保留所有文法及題目 ID、正解 ID 與題目數量。

## 結構驗證

執行單檔資料檢查：10 項、20 例句、30 個唯一題目 ID；每題四個不同 ID 的選項，且指定正解存在。對例句、題幹及日文選項共 90 個日文字串檢查標註格式，203 段 ruby 全部使用平假名讀音，未標註區段沒有漢字或「々」。未把繁中解說中的漢字當作日文假名缺漏。

這類檢查能確認格式與覆蓋，不能單獨證明讀音或文法完全正確。上表的語境判斷來自逐句重讀；正式教材仍適合另請日語教師校訂。
