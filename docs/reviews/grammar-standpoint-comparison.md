# 文法：立場與對象、比較與程度的交叉檢查

本輪由另一個 AI 開發代理獨立重讀既有初稿，檢查 10 個文法、20 句例句、30 題及 120 個選項的解說。範圍包含接續、繁中語意、使用限制、日文例句、全部假名、答案與錯項理由。這是 AI 輔助交叉檢查，沒有宣稱經日語教師或母語者專業審訂，也沒有宣稱逐項取得官方 JLPT 級別認證。

## 檢查範圍與重點

| 文法 | 本輪重點 |
| --- | --- |
| にとって | 是評價立場，不是行為對象；個人判斷不能擴大成所有人的事實。 |
| として | 區別身分、資格與用途；名詞直接接續，修飾名詞時可用「としての」。 |
| によって | 整句分辨「依條件而異」與「透過手段」；不將所有用法都翻成因為。 |
| に対して | 區別行為對象與情況對比；檢查名詞／な形容詞的「なのに対して」。 |
| について | 話題與行動對象不同；檢查「についての＋名詞」。 |
| ば～ほど | 動詞、い形容詞與な形容詞接續；程度連動不能變成一次性的保證。 |
| ほど～ない | 比較方向及否定範圍；沒那麼貴不等於免費，沒那麼擁擠不等於完全沒人。 |
| だけでなく～も | 前後兩項都成立；區別名詞、い形容詞、な形容詞接續。 |
| かわりに | 代替與優缺點取捨；名詞表示代替對象時用「のかわりに」。 |
| というより | 用更貼切的描述修正前項，不必完全否定前項，也不是單純的喜好比較。 |

## 採用的修正

- 「人によって、好きな音楽は違います」譯為「人們喜歡的音樂因人而異」，避免「每個人都不同」被誤解為所有人的喜好必須彼此互不相同。
- 「ば～ほど」說明明確寫成「『ば』前與『ほど』前重複同一個動詞或形容詞，並依各自需要活用」，避免把「前後重複」誤讀為兩個完整子句必須使用同一個述語。

重讀後未發現其他確定的假名誤讀或多個選項同時符合題目要求的情況。接續題明示目標句型；辨義與用法題將錯項設為比較方向相反、否定範圍錯誤、角色混淆或未被原句支持的推論，避免將本來可成立的近義說法任意判錯。

## 結構驗證與限制

另實際執行本檔的結構檢查：10 項各有 2 例句、3 種題型；每題 4 個不同選項且答案 ID 只對應一項。90 個日文欄位共 209 段 ruby 標註格式有效，所有日文漢字與「々」都包含讀音，沒有殘留標記。這能證明資料格式與覆蓋，不能自動證明每個讀音、自然度、語用或程度分類完全正確。

本輪依原稿與一般日語知識檢查，未另行查閱外部文法教材；不把 AI 檢查誤稱為外部教材逐項驗證。正式教材用途仍宜由日語教師或母語者校訂。
