# 拾語手帖：名稱與閱讀排版

本次依使用者指定將對外名稱改為「拾語手帖」。頁首、頁尾、瀏覽器標題、主畫面名稱、PWA manifest、安裝說明及專案文件一併更新；沿用原有色系、綠芽圖示與導覽架構。這是使用者指定的名稱變更，沒有將名稱描述為已完成商標查核或註冊。

## 字級

原本較小的內文、翻譯、操作按鈕、導覽與提示文字增加 1–2 CSS px；大型日文單字與主標題保留既有層級。同步檢查手機寬度的換行、觸控區域及文字是否溢出，避免只放大字體而壓縮閱讀空間。

## 單字標題假名

作答回饋、單字詳情及可展開的讀音提示改用原生 ruby，取代獨立、靠左的讀音文字列。以已整理的漢字／詞組為對位單位，例如：

- 節約：節＝せつ、約＝やく。
- 準備：準＝じゅん、備＝び；不因假名數量不同而平均切分。
- 取り替える：取＝と、替＝か；「り」「える」維持送假名，不重複加讀音。
- 真面目、支度等保留整詞讀法，不強行拆成沒有依據的單字讀音。
- 純假名單字直接顯示原文，避免重複一行相同文字。

`src/data/headword-readings.ts` 收錄全部 300 詞的標題對位；測試驗證還原後與原單字、完整讀音逐字一致，所有漢字皆有標註。這是文字讀音的對位，不是東京式高低音調或語音時間戳。

原有例句假名及全域「例句假名」切換繼續使用；標題讀音在單字詳情中維持可見，在作答前則仍須點「看看假名」才顯示。標題以原文字樣提供無障礙名稱，避免把分組讀音當成兩個分離的單字。

## 進度與更新

部署網址、PWA `id`／`scope`／`start_url`、資料庫名稱、單字及文法儲存鍵、題目 ID、備份格式均沿用，因此不需遷移學習資料。使用「更新網站」載入新版，無須清除網站資料。

已安裝主畫面捷徑的名稱由瀏覽器／作業系統控制，可能不會立即刷新；不要為了改捷徑標籤而清除學習資料。
