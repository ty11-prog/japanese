# 言葉の庭 · N3 日文單字

正式網站：[https://ty11-prog.github.io/japanese/](https://ty11-prog.github.io/japanese/)

為具備 N4 基礎的繁體中文學習者設計的手機優先 PWA。以每天約 15 分鐘為起點，透過主動回想、情境練習與間隔複習，逐步累積能理解、能記得的日文。

首版適合在單一裝置的 Chrome 使用，免登入、不需要後端或 API 金鑰。學習進度儲存在目前瀏覽器的 IndexedDB，不會上傳 GitHub 或其他雲端服務。

## 已提供的功能

- 300 個代表性詞彙（原有 100 詞加上 200 詞，五類各 60 詞），涵蓋日常生活、工作學習、情緒人際、社會資訊與動作表達；包含讀音、詞性、繁中釋義、原創例句、翻譯與搭配。
- 300 句例句皆提供漢字上方假名，可在例句或學習設定切換顯示，並保留這台裝置的偏好。填空題會連同答案的假名一起遮住。
- 先自行回想，再展開選項作答；另有依中文句意選詞的情境練習，以及裝置提供日文語音時可用的聽音辨詞。
- 到期複習優先，每日新詞預設 8 個，可調整為 4、8 或 12 個。15 分鐘是建議節奏，實際時間取決於待複習數量與作答情況。
- 依實際正誤與「再練一次／有點模糊／記得了／很熟悉」安排複習；答錯約 10 分鐘後再複習，且本輪稍後額外出現一次。較長間隔需要跨日、到期後的正確回想，同日重做不會連續刷成「較熟悉」。
- 單字搜尋、分類、學習狀態、近期紀錄與待加強詞彙。
- 進度自動儲存、JSON 匯出／匯入；匯入前驗證格式並要求確認覆蓋，無法自動合併兩份進度。若其他分頁已更新資料，舊分頁會停止寫入並提醒備份與重新整理，避免互相覆蓋。
- 正式建置具備可安裝 PWA 與離線快取；更新版本時由使用者選擇重新載入。

「N3」是選詞與學習目標，不是逐詞的官方級別認證。詞庫包含部分 N4 銜接複習，也不是完整考試範圍；內容尚未經日語教師或母語者全面審訂。詳見 [詞庫來源與校訂範圍](docs/content-sources.md)。

## 本機開發

使用 Node.js 24；`.nvmrc` 記錄本專案驗證使用的版本。

```sh
nvm use
npm ci
npm run dev
```

`nvm` 不是必要工具；若已安裝相容的 Node.js，可直接執行 npm 指令。開發服務預設使用 5173 埠，實際位址以終端輸出為準。

開發模式不啟用 Service Worker。要驗證安裝或離線功能，請使用正式建置預覽：

```sh
npm run build
npm run preview -- --port 4173 --strictPort
```

瀏覽器至少成功載入一次、完成離線快取後，才能在斷網狀態重新開啟。PWA 需要安全來源：正式部署使用 HTTPS；電腦上的 loopback 本機位址可供測試。手機透過區網 HTTP 開啟電腦服務時，通常無法驗證安裝與離線功能。

## 驗證

```sh
npm test
npm run build
npm run test:e2e
```

單元測試涵蓋複習排程、每日新詞上限、同日重試、IndexedDB 讀寫與備份驗證。瀏覽器測試使用桌面與手機尺寸，涵蓋主要學習流程、進度保存、備份、PWA 離線及基本無障礙檢查。自動化檢查不能取代實機 Chrome、實際語音與教材內容的人工驗證。

端對端測試會自行建置並在獨立的 4175 埠啟動正式預覽服務，每輪使用新瀏覽器環境，不沿用開發預覽的舊成品。雲端開發環境優先使用現有的 `/usr/bin/chromium`；其他電腦可安裝 Playwright 管理的 Chromium：

```sh
npx playwright install --with-deps chromium
npm run test:e2e
```

若要指定自己的 Chromium，設定 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 為其完整執行檔路徑。測試需要系統可啟動的瀏覽器；僅安裝 npm 套件不包含瀏覽器本體。

## 手機使用與資料保存

1. 在 Android Chrome 開啟正式 HTTPS 網站。
2. 完成首次載入，確認離線準備完成。可從 Chrome 選單選擇「加入主畫面」或「安裝應用程式」；選項名稱依裝置而異。
3. 正常完成作答後進度會自動寫入 IndexedDB。關閉頁面、重新開機或更新網站後，一般仍可保留同一來源的資料。
4. 定期到「學習設定」匯出 JSON 備份，可自行保存至手機、Google Drive 或個人 GitHub。網站不會自動將資料同步到這些空間。

進度屬於同一個瀏覽器及網站來源（協定、網域與埠號）。換瀏覽器、換網址、清除網站資料、無痕模式結束或瀏覽器清理儲存空間，都可能造成無法取得原進度。從開發埠換到預覽埠也是不同來源；需要以匯出／匯入搬移。程式會嘗試申請瀏覽器的持續儲存，但是否核准由瀏覽器決定，不能取代備份。若出現讀寫失敗提示，應先匯出目前可取得的進度，不要將畫面仍能作答視為已成功持久保存。讀取失敗不會被當作新使用者而自動覆寫原資料；儲存異常時亦不會允許透過版本更新按鈕直接重新載入。

日文發音使用手機／瀏覽器提供的日文文字轉語音，並非真人錄音。在「學習設定」可試聽並選擇聲音、設定 0.8／1／1.1 倍預設語速；正常速度為 1 倍，例句另有「慢速播放」。自動選聲會參考聲音名稱的品質提示，仍無法保證每台手機的音色自然度。播放時傳送原始日文，不會將畫面上的假名重複念出。

Android 可在系統「文字轉語音輸出」下載日文語音，並在網站設定測試。若沒有可用的日文語音，聽音練習不會開放；遠端聲音需要連線，離線時會暫用可用的本機日文語音。聲音與假名顯示偏好儲存在本機 localStorage，學習進度仍保存在原本的 IndexedDB；目前進度 JSON 備份不包含這些顯示與語音偏好。

## 部署

網站已透過 GitHub Pages 發布。更新時先提交並推送程式碼，再手動執行 GitHub Pages workflow；流程包含安裝、單元測試、建置與部署，一般 push 不會自動發布。詳見 [部署說明](docs/deployment.md)。

GitHub Pages 提供的是靜態網站。儲存庫或網站公開不會使手機的 IndexedDB 學習進度自動公開；網站檔案本身不得放入 token、密鑰或個人進度備份。私人儲存庫也不保證 Pages 網站是私人網站，實際可見性與可用性依 GitHub 方案及設定而定。
